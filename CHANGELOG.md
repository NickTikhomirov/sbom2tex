# sbom2tex changelog

## 1.0.1

### Изменения и фиксы:

+ Дистрибуция контейнера Texlive заменена на Gitlab разработчика (вместо dockerhub);
+ Улучшены описания флагов;
+ Улучшено поведение флага `-t` для моноотчёта (в части опций `N` и `k`)
+ BUGFIX: добавлено экранирование фигурных скобок (`{` и `}`) в LaTeX;
+ BUGFIX: добавлено экранирование циркумфлекса (`^`) в LaTeX;
+ BUGFIX: дедупликация компонентов больше не нарушает работу с уязвимостями;
