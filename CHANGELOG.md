# sbom2tex changelog

## 1.1.0

### Нововведения

+ Во вводный блок добавлена статистика по языкам;

### Изменения и фиксы

+ Теперь при печати компонентов в табличной форме (`-T`) поле provided_by входит в источники, а соответствющий столбец удалён
+ Изменена документация (кому не всё равно?)
+ Попытка сократить список директивных LaTeX-зависимостей (убраны 6 неиспользуемых пакетов)
+ Незначительные исправления внешнего вида (где-то добавлены пробелы, в какие-то ячейки добавлен полужирный текст)

## 1.0.1

### Изменения и фиксы

+ В шаблон отчёта был добавлен fancyhdr, который когда-нибудь будет использован для красивых колонтитулов
+ Титульный лист вынесен в отдельную директорию, что может упростить его замену с целью кастомизации
+ Дистрибуция контейнера Texlive заменена на Gitlab разработчика (вместо dockerhub);
+ Улучшены описания флагов;
+ Улучшено поведение флага `-t` для моноотчёта (в части опций `N` и `k`);
+ Теперь флаг `--no-gost` влияет на статистику в вводной части;
+ Отключены переносы (hyphenation)
+ Изменён порядок экранирования двойных кавычек
+ BUGFIX: добавлено экранирование фигурных скобок (`{` и `}`) в LaTeX;
+ BUGFIX: добавлено экранирование циркумфлекса (`^`) в LaTeX;
+ BUGFIX: дедупликация компонентов больше не нарушает работу с уязвимостями и подсчёт оценок проекта;
+ BUGFIX: исправлено предупреждение Python о некорректной эскейп-последовательности (это не влияло на работоспособность, но немного отвлекало);
+ BUGFIX: теперь инструменты генерации SBoM дедуплицируются перед печатью;
+ BUGFIX: в список языков больше не попадают пустые строки;
+ BUGFIX: исправлен обход графа, который мог зациклиться;
