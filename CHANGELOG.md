# sbom2tex changelog

## 1.1.0

### Нововведения

+ Во вводный блок добавлена статистика по языкам;
+ Добавлен флаг `-x`, через который можно настроить количество перекомпиляций проекта при использовании флага `--compile`;
+ Добавлен флаг `--no-advertisements`, который отключает блок со списком инструментов композиционного анализа;
+ Теперь после сборки удаляются все вспомогательные файлы -- остаются только `.pdf` и `.tex` (и исходные json-файлы, конечно же);
+ Добавлена возможность переопределить описание документа, используя флаг `--intro-text` со строковым аргументом;
+ Добавлен флаг `--no-cmp`, который отключает раздел компонентов;
+ Добавлен раздел с группировкой компонентов по имени -- для включения используется флаг `-N`;
+ Добавлены флаги `--no-toc` для отключения оглавления и `--fake-aux` для подделывания файла `report.aux` -- оба этих флага нужны, чтобы компиляция LaTeX проходила с первого раза (т.е. флаг `-x 1` выдавал приемлемый результат);
+ В репозиторий добавлен новый скрипт `bdu_top5_enricher.py` для соотнесения CVE по их CWE с веб-уязвимостями БДУ (и вспомогательный скрипт `parse_cwe_xml.py`, которым был сгенерирован код первого -- парсит официальную XML со всеми CWE в граф);
+ Добавлен флаг `-+`, который позволяет подключать другие флаги из текстового файла;
+ Добавлен маппинг веб-уязвимостей БДУ на найденные CVE -- для обогащение можно использовать новый флаг `--enrich-bdu-web` (передайте флаг два раза, если нужен полный обход CWE вместе с детьми);

### Изменения и фиксы

+ Больше не назначается severity=7.5 для уязвимостей без назначенной численной оценки;
+ Теперь при печати компонентов в табличной форме (`-T`) поле provided_by входит в источники, а соответствющий столбец удалён;
+ Теперь при печати компонентов в табличной форме (`-T`) шапка таблицы повторяется на каждой странице;
+ Изменена документация (кому не всё равно?)
+ Попытка сократить список директивных LaTeX-зависимостей (убраны 6 неиспользуемых пакетов);
+ Исправления внешнего вида (где-то добавлены пробелы, в какие-то ячейки добавлен полужирный текст)
+ Добавлено сообщение о том, что не было найдено ни одной уязвимости, чтобы раздел "Уязвимости" не был пустой в таком случае;
+ Поменялся набор флагов, включаемых флагом `-O`;
+ BUGFIX: добавлено экранирование `<` и `>` (для обработки случаев `<<` и `>>`), а также `--`
+ BUGFIX: теперь слова в описании CVE, которые длиннее строки карточки, переносятся, а не "протекают"; -- механизм, в целом, налажен, так что надо будет найти все остальные места, где такой функционал нужен
+ BUGFIX: `--no-gost` теперь принудительно отключает флаг `--review-attack-surface`;
+ BUGFIX: Исправлена отрисовка таблицы компонентов при флаге `--no-cve`;

## 1.0.1

### Изменения и фиксы

+ В шаблон отчёта был добавлен fancyhdr, который когда-нибудь будет использован для красивых колонтитулов
+ Титульный лист вынесен в отдельную директорию, что может упростить его замену с целью кастомизации
+ Дистрибуция контейнера Texlive заменена на Gitlab разработчика (вместо dockerhub);
+ Улучшены описания флагов;
+ Улучшено поведение флага `-t` для моноотчёта (в части опций `N` и `k`);
+ Теперь флаг `--no-gost` влияет на статистику в вводной части;
+ Отключены переносы (hyphenation)
+ Изменён порядок экранирования двойных кавычек
+ BUGFIX: добавлено экранирование фигурных скобок (`{` и `}`) в LaTeX;
+ BUGFIX: добавлено экранирование циркумфлекса (`^`) в LaTeX;
+ BUGFIX: дедупликация компонентов больше не нарушает работу с уязвимостями и подсчёт оценок проекта;
+ BUGFIX: исправлено предупреждение Python о некорректной эскейп-последовательности (это не влияло на работоспособность, но немного отвлекало);
+ BUGFIX: теперь инструменты генерации SBoM дедуплицируются перед печатью;
+ BUGFIX: в список языков больше не попадают пустые строки;
+ BUGFIX: исправлен обход графа, который мог зациклиться;
