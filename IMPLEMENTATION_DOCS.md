
## Список исходных файлов

+ `main.py` -- основной файл, содержащий флаги и вызывающий печать отчёта
+ `src/messages.py` -- файл, содержащий логику по написанию больших объёмов текста для отчёта
+ `src/report_boilerplate.py` -- файл, содержащий преамбулу LaTeX и код раздела "общие сведения"
+ `src/sbom_lib.py` -- файл, содержащий логику работы со SBoM-ами -- парсинг, добавление рёбер...
+ `src/sbom_to_tex.py` -- файл, содержащий логику конвертации компонентов и уязвимостей в LaTeX-код;
+ `src/tex_table.py` -- файл, предоставляющий обёртку над LaTeX-таблицами;
+ `src/tex_utils.py` -- файл с цветами, функцией экранирования пользовательского ввода и прочими полезными мелочами;
+ `src/os_helper.py` -- файл с кодом для работы с файловой системой;
+ `src/title/title.py` -- файл с кодом титульника.

## Использованные библиотеки для LaTeX

В качестве фреймворка компиляции используется XeLaTeX. Не рекомендуется заменять его на аналоги, потому что все они чуть-чуть различаются, и полученный результат может отличаться от авторской задумки.
Для успешной сборки также нужны пакеты:
+ основные пакеты:
  + `xcolor` -- нужен примерно для всего, что есть разноцветного в документе;
  + `fontspec` -- пакет для настройки размера и типа шрифта;
+ работа со страницами:
  + `geometry` -- пакет для настройки размера бумаги, полей и всего такого;
  + `pdflscape` -- пакет для работы с альбомной ориентацией;
+ работа с таблицами:
  + `longtable` -- пакет для работы с многостраничными таблицами (работает плохо, но жрёт мало памяти);
  + `tabularray` -- пакет для работы с многостраничными таблицами `longtblr` (работает хорошо, но жрёт много памяти);
  + `multirow` и `multicol` -- пакеты для объединения ячеек в таблице (на данный момент multirow в проекте не используется);
  + `array` -- вспомогательный пакет для работы с таблицами (например, для колонок фиксированной ширины);
+ работа со ссылками:
  + `hyperref` -- пакет для гиперссылок (в документе нет гиперссылок кроме `\url` и оглавления);
  + `xurl` -- пакет для продвинутой команды `\url`, которая позволяет переносить ссылки в любом месте;
+ другое:
  + `indentfirst` -- пакет для красной строки на первом абзаце в каждой главе (LaTeX по умолчанию добавляет красную строку всем абзацам кроме первого);
  + `fancyhdr` -- пакет для работы с колонтитулами -- не исползуется на данный момент, зарезервирован;
  + `seqsplit` -- пакет для переноса текста "где угодно";
  + `babel` -- вроде, в проекте влияет только на то, что "содержание" называется по-русски, а не "contents";
+ `tcolorbox` -- для оформления заголовка на титульнике
+ `tikz` -- для рамки на титульнике (и да, я в курсе, что тащить tikz ради всего одной рамки на титульнике -- это одно из самых страшных преступлений в LaTeX-комьюнити)
  + tikz-библиотека `calc`
  + tikz-библиотека `decorations.pathmorphing`
+ ... а также соответствующие транзитивные зависимости.

Встроенный флаг компиляции использует XeLaTeX и latexmk.

В случае стандартного использования через Docker-контейнер, все пакеты уже установлены в составе дистрибутива Texlive, равно как и xelatex с latexml.
